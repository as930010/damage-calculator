# 傷害計算機

線上遊戲裝備搭配與傷害試算工具，支援多個職業。選擇職業與裝備後，即可查看角色屬性與攻擊結果，並比較不同配裝。

## 開始使用

前往[傷害計算機](https://as930010.github.io/damage-calculator/)，在瀏覽器中選擇職業、裝備與其他設定。點選「設為比較基準」後，可以查看目前配置與基準配置的差異。

頁面右上方可切換明亮模式與暗色模式；選擇會保存在目前瀏覽器中。

配裝設定會保存在目前瀏覽器的本機儲存空間，不會提交到網站。更換瀏覽器或清除網站資料後，先前保存的設定可能無法保留。

## 關於試算結果

結果依目前工具提供的遊戲資料與可用設定計算。若某個來源或效果尚未提供選項，該效果不會自動加入試算；請以遊戲內實際結果為準。
